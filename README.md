# Logit Computer GmbH Website

Eine moderne, professionelle Website für Logit Computer GmbH - Ihr verlässlicher IT-Partner.

## Features

- **Responsive Design**: Optimiert für alle Geräte (Desktop, Tablet, Mobile)
- **Modernes UI/UX**: Klares, professionelles Design mit ansprechenden Animationen
- **Scroll-Animationen**: Elemente werden beim Scrollen sanft eingeblendet
- **Interaktive Navigation**: Mobile-optimierte Navigation mit Smooth Scrolling
- **Kontaktformular**: Validiertes Formular mit Benachrichtigungen
- **Performance-optimiert**: Schnelle Ladezeiten durch optimierten Code

## Struktur

```
logit/
├── index.html          # Hauptseite mit allen Sektionen
├── styles.css          # Komplettes Styling
├── script.js           # JavaScript für Interaktivität
└── README.md          # Diese Datei
```

## Sektionen

1. **Hero Section**: Einprägsamer Einstieg mit Call-to-Action
2. **Services**: Übersicht über alle IT-Dienstleistungen
3. **About**: Informationen über das Unternehmen mit Statistiken
4. **Why Us**: Vorteile und Alleinstellungsmerkmale
5. **Contact**: Kontaktformular und Kontaktinformationen
6. **Footer**: Links und rechtliche Informationen

## Technologien

- HTML5
- CSS3 (mit CSS Grid und Flexbox)
- Vanilla JavaScript (ES6+)
- Google Fonts (Inter)

## Design-Prinzipien

- **Farbschema**: Professionelles Blau (#2563eb) als Hauptfarbe
- **Typografie**: Inter-Schriftfamilie für moderne Lesbarkeit
- **Spacing**: Konsistente Abstände für harmonisches Layout
- **Animationen**: Subtile Übergänge für bessere UX

## Verwendung

### Lokal öffnen

Öffnen Sie einfach die `index.html` Datei in einem modernen Browser.

### Mit lokalem Server

```bash
# Python 3
python -m http.server 8000

# Node.js (mit npx)
npx serve

# PHP
php -S localhost:8000
```

Dann öffnen Sie `http://localhost:8000` in Ihrem Browser.

## Anpassungen

### Farben ändern

Bearbeiten Sie die CSS-Variablen in `styles.css`:

```css
:root {
    --primary-color: #2563eb;
    --primary-dark: #1e40af;
    /* ... weitere Farben */
}
```

### Inhalte anpassen

Bearbeiten Sie die Texte direkt in `index.html`.

### Kontaktinformationen

Aktualisieren Sie die Kontaktdaten im Contact-Bereich:
- Telefonnummer
- E-Mail-Adresse
- Physische Adresse
